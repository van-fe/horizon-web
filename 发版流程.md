# 发版流程

1. 修改 `./versions.json` 的版本号
2. `modify:version`
3. `bun install`
4. `build`
5. 发布：
   - 最新版: `npm run pub -- --confirm`
   - alpha版: `npm run pub -- --confirm --tag alpha`
   - beta版: `npm run pub -- --confirm --tag beta`
   - 2-x版: `npm run pub -- --confirm --tag v2-x`
   - 2-x alpha版: `npm run pub -- --confirm --tag v2-x-alpha`
   - 2-x beta版: `npm run pub -- --confirm --tag v2-x-beta`
