# Display
样式工具类，用来设置元素的 CSS `display` 属性。

|Class|Properties|
|-|-|
|hidden|display: none;|
|block|display: block;|
|inline-block|display: inline-block;|
|inline|display: inline;|
|flex|display: flex;|
|inline-flex|display: inline-flex;|
|grid|display: grid;|
|inline-grid|display: inline-grid;|
