
### 组件说明
和其它所有组件库都不同，我们提供的是指令而非组件的方式来实现这一效果。这样做的好处是，你无需修改元素的结构，也无需手动将目标元素上的 `click` 事件移到气泡弹窗上 —— 这一切都是自动的。

### 基础示例
给需要二次确认的操作元素加上 `v-popconfirm` 即可，它会自动将元素的 `click` 事件转移到弹窗中。
:::demo ./demos/basic.vue :::

### 自定义文本
你可以通过给 `v-popconfirm` 传入一个字符串来重新设置文本，也可以传入一个完整的配置对象。
:::demo ./demos/title.vue :::

### 自定义类型
通过 `type` 传入想要的类型，这会对应不同的图标，`none` 表示不显示图标。
:::demo ./demos/type.vue :::

### 自定义位置
气泡弹窗的位置默认是 `top`，有 15 个可选值。
:::demo ./demos/placement.vue :::

### 自定义按钮
你可以完全自定义按钮的文本和参数。
:::demo ./demos/customize.vue :::
