### 垂直方向
默认情况下，面板具有水平的动画效果，且会自动监听切换方向是从左到右，还是从右到左，显示最恰当的动画。你也可以通过设置 `vertical` 启用垂直方向的动画。
:::demo ./demos/vertical.vue :::

### 附加样式
为提高灵活度，面板尽可能不自带无关样式，你可以通过 [Styles & Animation](/lego/style-animation) 中的工具类或 `style` 来附加想要的样式。
:::demo ./demos/style.vue :::
