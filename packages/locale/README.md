# @aurora/locale

## What is it
It is a basic library for `horizon-web ui` to provide multiple locale methods.

## Attention
**DO NOT USE IT DIRECTLY!!!**

You should use `@aurora/locale-vue` or `@aurora/locale-react` instead of this.

## How to Install
```bash
bun add @aurora/locales
```

## How to use
```typescript
import LocaleService from "@aurora/locale";

new LocaleService({ current: 'En' });
```
