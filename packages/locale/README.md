# @nio-fe/locale

## What is it
It is a basic library for `lego ui` to provide multiple locale methods.

## Attention
**DO NOT USE IT DIRECTLY!!!**

You should use `@nio-fe/locale-vue` or `@nio-fe/locale-react` instead of this.

## How to Install
```bash
pnpm add @nio-fe/locales
```

## How to use
```typescript
import LocaleService from "@nio-fe/locale";

new LocaleService({ current: 'En' });
```
