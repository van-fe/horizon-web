# Border radius
样式工具类，用来设置元素的圆角。

|Class|Properties|
|-|-|
|rounded-0|border-radius: 0;|
|rounded-sm|border-radius: var(--n-radius-base) / 2; /* 2px */|
|rounded|border-radius: var(--n-radius-base); /* 4px */|
|rounded-lg|border-radius: var(--n-radius-base) * 2; /* 8px */|
|rounded-xl|border-radius: var(--n-radius-base) * 3; /* 12px */|
|rounded-pill|border-radius: 99999px;|
|circle|border-radius: 50%;|
