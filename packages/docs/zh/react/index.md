# React API 及示例

这里汇总 `@aurora/horizon-react` 的组件文档。当前提供 Button 和 Switch，后续组件会在完成实现和验证后加入左侧导航。

```bash
bun add @aurora/horizon-react react react-dom
```

在应用入口加载一次样式：

```tsx
import '@aurora/horizon-react/style.css';
```
