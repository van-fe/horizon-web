# 扩展

扩展包为 Horizon Web 提供可独立安装的能力，不会把第三方 SDK 或特定业务依赖引入组件库核心。

## 可用扩展

- [Locale Vue](./locale-vue)：为 Vue 3 应用提供翻译、日期、数字格式化组件和阅读方向指令。
- [Locale React](./locale-react)：为 React 应用提供作用域 Provider、响应式 Hook、格式化组件和阅读方向能力。
- [Upload Adapters](./upload-adapters)：为 Upload 提供七牛 Kodo、阿里云 OSS 和腾讯云 COS 的分片断点续传预设。
