### 数字
你还可以展示一个数字类型的标记，并限定最大值。
:::demo ./demos/num.vue :::

### 颜色
你可以自定义标记的颜色。
:::demo ./demos/color.vue :::

### 图标
支持将一个图标作为标记内容。
:::demo ./demos/icon.vue :::

### 显示隐藏
默认情况下标记总是显示，即使是数字类型且值为 `0` 的情况，你可以通过 `hidden` 属性完全控制标记的显示状态。
:::demo ./demos/hidden.vue :::
