## 显示位置

`placement` 支持围绕触发元素的 12 个方向。示例可切换尺寸、主题和延迟，并显示最近触发的位置。

:::demo components/Tooltip/placement.vue :::

## 宽度与溢出

通过 `width` 约束长内容宽度；开启溢出检测后，只在文本被截断时展示提示。

:::demo components/Tooltip/width.vue :::

## 可移入与复制

开启 `enterable` 后，指针可以进入浮层并操作其中内容；`click-to-copy` 可复制浮层文本或指定目标内容。

:::demo components/Tooltip/enterable.vue :::

## 尺寸与箭头

提示支持 `large`、`medium`、`small` 三种尺寸，并可关闭箭头。示例同时展示显示与隐藏事件反馈。

:::demo components/Tooltip/size.vue :::

## 主题

`dark` 适合常规界面提示，`light` 适合深色或强调背景。应根据相邻背景保持足够对比度。

:::demo components/Tooltip/theme.vue :::
