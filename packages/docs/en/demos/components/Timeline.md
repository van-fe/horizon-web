## When to use

Use a timeline for milestones, state changes, or activity records arranged by time. Forward and reverse order support different reading directions.

## Basic style

A timeline combines nodes, connecting lines, timestamps, names, and descriptions. The example compares all three sizes for different content densities.

:::demo components/Timeline/basic.vue :::

## States and ordering

Configure node types, colors, icons, dashed lines, and folded content, or customize names and descriptions with slots. The example includes an order control for the complete reading flow.

:::demo components/Timeline/prop.vue :::

## `format` values

`format` accepts a Day.js format string directly. See the [Day.js format documentation](https://day.js.org/docs/en/display/format) for available tokens.
