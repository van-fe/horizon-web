
## Fade

`fade-in-linear` uses constant opacity timing, while `fade-in` uses easing.

:::demo components/Transition/fade.vue :::

## Zoom

Choose a transform origin with a `zoom-in-*` name and control duration with `speed`.

:::demo components/Transition/zoom.vue :::

## Collapse

`collapse` animates vertical size and `collapse-horizontal` animates horizontal size. Prevent horizontal content from wrapping during the transition.

:::demo components/Transition/collapse.vue :::

## Slide

Use `slide-up`, `slide-right`, `slide-down`, or `slide-left` to select the entry direction.

:::demo components/Transition/slide.vue :::

## List Movement

Set `group` and use `float` to animate list items into their new positions after insertion or removal.

:::demo components/Transition/float.vue :::
