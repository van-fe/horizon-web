## Basic Usage

CommandPalette provides a keyboard-first entry point for global actions. Open it from a trigger or with Command/Ctrl + K, type to filter, move with the arrow keys, and press Enter to execute.

Use `commands` for labels, descriptions, keywords, shortcuts, and disabled states. Listen to `search` for query feedback and `select` for the executed command.
