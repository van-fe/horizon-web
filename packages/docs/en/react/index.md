# React API and Examples

This section documents `@aurora/horizon-react`. Button and Switch are currently available; more components will appear in the sidebar after their implementation and validation are complete.

```bash
bun add @aurora/horizon-react react react-dom
```

Load the renderer stylesheet once at the application entry:

```tsx
import '@aurora/horizon-react/style.css';
```
