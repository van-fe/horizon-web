# Display
Style utility classes for setting element CSS `display` property.

|Class|Properties|
|-|-|
|hidden|display: none;|
|block|display: block;|
|inline-block|display: inline-block;|
|inline|display: inline;|
|flex|display: flex;|
|inline-flex|display: inline-flex;|
|grid|display: grid;|
|inline-grid|display: inline-grid;|
