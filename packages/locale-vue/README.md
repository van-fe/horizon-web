# @nio-fe/locale-vue

## What is it
It is a library for `lego ui` to provide multiple locale methods.

It is based on `@nio-fe/locale` and `vue@3+`.

## How to Install
```bash
pnpm add @nio-fe/locales-vue
```

## How to use
```typescript
import {app} from 'vue';
import VueLocaleService from "@nio-fe/locale-vue";

app.use(VueLocaleService);
```
